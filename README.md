# Motion Potion · 2026 site preview

Kyle Parsons' portfolio with a painterly treatment of his original 3D sculpt, an abstract lavender portrait frame, cursor-following head and eyes, and buttons that sit raised and press down on hover or keyboard focus.

## Preview and build

Run `node server.mjs` and open `http://localhost:4173`. No package install is required. Set `PORT` to use a different local port. JavaScript modules need an HTTP server.

Run `npm run check` to check JavaScript syntax and `npm run build` to prepare `dist/`. The existing `.github/workflows/pages.yml` workflow deploys that directory to GitHub Pages. All site asset paths are relative, so repository subpaths are supported. The site is published at https://nerdlykyle.github.io/motionpotion/. The custom domain is not connected yet; DNS still points to Wix.

## Portrait

**Approved character — September 27, 2026:** After approving the Prism v2 cleanup and animated review, Kyle requested this version replace the site's earlier original model. The current web asset is `assets/models/kyle-prism-v2-web.glb`. It includes repaired round eyes, matched irises/pupils, shirt buttons, full brow coverage, eyelid morphs and the head/quiff/brow rig. The graphic-style adaptation and from-scratch sculpt studies remain rejected. Future character work should start from this approved Prism v2 version.

The header uses `assets/potion-3d.webp`, a transparent two-second render of the Blender potion concept. A responsive picture source selects `assets/potion-3d-still.webp` when reduced motion is preferred. `assets/potion-still.svg` retains Kyle's original artwork for the favicon. The editable scene remains in `assets/3d model/potion-concept/`; the header animation needs no WebGL or extra JavaScript. Edit source assets rather than `dist/`, which is regenerated by the build.

- `assets/models/kyle-prism-v2-web.glb` is the approximately 23 MB browser copy, with a simplified body and 2048px main texture. The full-resolution rigged GLB, Blender source, and review files remain under `assets/3d model/prism-v2-cleanup/`. The earlier site model is preserved for rollback but is no longer loaded or copied into fresh builds.
- `painterly.js` uses the approved review's object-position-anchored brush cells across the whole character, including moving eyes and eyelids. Paint strength is 1.0 and brush scale is 1.4. The separate Blender compositor remains in the authoring source; GLB does not contain compositor effects.
- `character.js` preserves the exported `Root`, `Head`, `Quiff`, `Brow_L` and `Brow_R` bones. `character-motion.js` makes the eyes lead, with the head following 110 ms later. Eyelids close in 3–5 reference frames at 30 fps, briefly hold, and reopen in 2–4 frames. Blink intervals vary, with occasional double blinks; the lower lid and brows follow slightly later. `BlinkArc = 4*t*(1-t)` keeps the moving lids outside the spherical eyeballs.
- Head turns are limited to about 13 degrees horizontally and 8 degrees vertically. Eye movement adds a smaller turn. “Say hi” gives a short nod on hover, keyboard focus, or click and takes visitors to the contact form. The link works independently of the 3D model and motion preference.
- The exported quiff bone uses the damped spring in `character-motion.js`, lagging behind head turns, greeting nods, and mobile scroll gaze. Motion pauses offscreen and in hidden tabs; reduced-motion preferences keep a still portrait. `tests/character-motion.test.mjs` verifies timing, frame-rate independence, and safe motion limits.
- `assets/kyle-prism-v2-portrait.png` is the matching transparent loading/WebGL fallback rendered with the site's camera, lighting and paint pass. The About section's existing over-the-shoulder editing video remains separate from this interactive hero replacement.
- System reduced-motion preferences, offscreen suspension, and hidden-tab suspension are supported. Touch interaction is limited to the portrait so scrolling elsewhere does not move the gaze.
- The lavender shape and portrait mask share the same lower silhouette, while the top of the head remains outside the frame.

## Deployment assets

The build copies public images, fonts, vendor scripts, and the lightweight web GLB. It excludes the `assets/3d model/` authoring directory, Blender scenes, and cleanup references. Do not add those authoring files to `dist/` manually.

Portfolio videos are served from `assets/videos/` through GitHub Pages, so the site no longer depends on Wix video hosting. The About section retains the public LinkedIn profile link.

The contact form collects name, reply email and message. It submits to FormSubmit's static-site endpoint for kyle@motionpotion.studio, with the subject “A new idea is brewing — Motion Potion”. A server-checked `_honey` field sits visually offscreen, outside keyboard and screen-reader navigation. FormSubmit's default CAPTCHA and spam filtering remain enabled. The form submits normally so a CAPTCHA challenge can run when needed; JavaScript supplies an absolute return URL and shows confirmation when FormSubmit sends the visitor back. Without JavaScript, FormSubmit shows its own thank-you page. FormSubmit must be activated before normal delivery: submit one real message and click the confirmation link sent to kyle@motionpotion.studio. The confirmation email may land in spam. Do not consider inbox delivery verified until that step is complete. FormSubmit handles the submitted contact details and retains submissions under its own policy.
